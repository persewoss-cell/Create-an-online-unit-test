# 온라인 단원평가

교사가 **문제 PDF와 정답 PDF**를 올리면 온라인 평가로 바뀌고, 학생은 **학년·반·번호·이름**으로 들어와 평가를 본 뒤 **바로 자동 채점 결과**를 확인합니다. 교사는 결과를 **엑셀로 내려받고**, 자동 채점이 애매한 답안은 **검토 요청** 목록에서 직접 정답/오답을 정합니다.

## 주요 기능

| 구분 | 기능 |
| --- | --- |
| 교사 | 이메일 로그인(교사 가입 코드 필요) · 과목/학년/학기/단원 입력 · 문제·정답 PDF 업로드 → 자동 인식 → 확인·수정 후 저장 |
| | 응시 열기/마감 · 응시할 반 지정 · 채점 기준(엄격/보통/관대) · 학생에게 정답 공개 여부 |
| | 결과표(O/X/? 클릭으로 판정 변경) · 검토 요청 목록 · 문항별 정답률 · 엑셀 다운로드(성적/답안/문항분석) · 재응시 허용 |
| 학생 | 학년·반·번호·이름 입력 → 우리 학년/반에 열린 평가 선택 |
| | **왼쪽: 문제지, 오른쪽: 답안지** (객관식은 선택, 단답형은 입력칸, 서술형은 여러 줄 입력칸) |
| | 한 문항이라도 비어 있으면 제출 불가 · 1회만 응시 · 제출 즉시 점수 확인 |

## PDF 자동 인식 (규칙 기반, AI 미사용)

과목마다 양식이 달라도 **번호가 1부터 차례로 늘어난다는 점**을 이용해 문항을 찾습니다. 2단 편집 시험지도 자동으로 감지합니다.

- **문항 번호**: `1.` `1)` `1번` `문제 1` `문항 1` `[1]` `【1】` `Q1` `1 다음 중…`
- **보기**: `①~⑤` 또는 `(1)~(5)` → 객관식, 보기 수 자동 계산. `모두 고르시오`는 복수 정답 문제로 처리
- **서술형 감지**: `서술하시오`, `설명하시오`, `이유를 쓰시오` 등
- **배점**: `[5점]`, `(5점)` → 자동 입력. 없으면 100점을 나눠 줍니다.
- **정답지**: `1. ③` · `1③ 2① 3④` · `1번 답: 광합성` · 표(`번호 1 2 3` / `정답 ③ ① ④`) · `예시 답안: …`
  - `해설`, `풀이`, `채점 기준` 뒤의 내용은 정답에서 제외
  - `광합성 / 광합성 작용`, `광합성(또는 탄소 동화)` → 여러 정답 인정
  - 서술형에 `핵심어: 물|수분, 건조, 줄` 줄이 있으면 채점 기준으로 사용 (없으면 모범 답안에서 자동 추출)

인식 결과는 저장 전에 화면에서 확인·수정할 수 있고, 정답 PDF가 없거나 인식이 안 되면 **“정답 빠르게 입력하기”**(`1.③ 2.④ 3.광합성`)를 쓰면 됩니다. 글자가 없는 **스캔 이미지 PDF**는 문항 수를 직접 입력해 답안 칸을 만들 수 있습니다(문제지는 이미지로 그대로 보입니다).

> 올리기 전에 인식 결과를 미리 보고 싶다면: `node scripts/inspect-pdf.mjs 문제.pdf 정답.pdf`

## 자동 채점 기준

| 유형 | 정답 처리 | 교사 검토 요청 | 오답 |
| --- | --- | --- | --- |
| 객관식 | 번호 일치 (복수 정답은 모두 골라야 함) | – | 그 외 |
| 단답형 | 띄어쓰기·문장부호·조사/어미 차이 무시 (`광합성입니다`), 활용형 차이 무시 (`많아진다`≈`많아져요`), 숫자·단위 (`24`≈`24개`, `3/4`≈`4분의 3`), 정답을 포함한 포괄적 답 | 오타로 보이는 답, 일부만 맞은 답, 단위가 다른 답 | 그 외 |
| 서술형 | 핵심어를 충분히 포함 (보통: 60% 이상) | 핵심어 일부 포함, 핵심어는 맞지만 부정 표현(`않다`)이 모범 답안과 다른 경우 | 핵심어가 거의 없음 |

검토 대기 문항은 교사가 판정할 때까지 0점으로 계산되고, 학생 결과 화면에는 `?`로 표시됩니다. 교사가 판정하거나 정답을 수정하면 **모든 학생 점수가 즉시 다시 계산**됩니다.

## Firebase 설정 (처음 한 번)

무료 요금제(Spark)로 충분합니다. Cloud Functions나 Storage는 쓰지 않습니다.

1. [Firebase 콘솔](https://console.firebase.google.com)에서 프로젝트 만들기
2. **Authentication → 로그인 방법**에서 **이메일/비밀번호**와 **익명**을 사용 설정
3. **Firestore Database → 데이터베이스 만들기** (프로덕션 모드, 위치: `asia-northeast3 (서울)`)
4. **Firestore → 데이터**에서 컬렉션 `config`, 문서 ID `signup`, 필드 `code`(문자열) = 교사 가입 코드(예: `우리학교2026`) 추가
   - 이 코드를 아는 사람만 교사로 가입할 수 있습니다. 학생들에게 알려주지 마세요.
5. **프로젝트 설정 → 내 앱 → 웹 앱 추가** 후 표시되는 설정값을 `.env` 파일에 입력
   ```bash
   cp .env.example .env   # 값 채우기
   cp .firebaserc.example .firebaserc   # 프로젝트 ID 입력
   ```
6. 설치 및 배포
   ```bash
   npm install
   npx firebase login
   npm run deploy        # 사이트(Hosting) + 보안 규칙(firestore.rules) 배포
   ```
   배포가 끝나면 `https://<프로젝트ID>.web.app` 주소로 접속합니다. 교사 관리 페이지는 학생 화면 아래의 “교사용 관리 페이지” 링크(또는 `/#/teacher`)입니다.

## 개발

```bash
npm install
npm test               # 인식·채점 단위 테스트
npm run dev            # .env 의 실제 Firebase에 연결

# 실제 Firebase 없이 로컬 에뮬레이터로 (Java 필요)
npm run emulators      # 터미널 1
npm run dev:emulator   # 터미널 2 → http://localhost:5173
npm run test:rules     # 터미널 3: 보안 규칙 점검
```

에뮬레이터에서 교사 가입을 하려면 `config/signup` 문서가 필요합니다. `npm run test:rules`를 한 번 실행하면 가입 코드가 `TEST-CODE`로 만들어집니다.

`samples/` 폴더에 과목별로 양식이 다른 예시 문제·정답 PDF(과학 2단+표 정답지, 수학, 국어)가 있습니다.

## 데이터 구조와 보안

```
teachers/{uid}                        교사 프로필
config/signup                         교사 가입 코드 (누구도 읽을 수 없음)
exams/{id}                            평가 정보 + 문항(정답 없음)
exams/{id}/pages/{n}                  문제지 페이지 이미지
exams/{id}/private/key                정답 — 교사 본인, 또는 제출을 마친 학생만 읽기 가능
exams/{id}/submissions/{학년-반-번}   학생 답안 — 한 번만 만들 수 있고 학생은 수정 불가
exams/{id}/submitters/{uid}           제출 표시
```

- 학생은 익명 로그인을 사용하며, 로그인할 때마다 새 세션이 만들어져 **공용 PC에서도 안전**합니다.
- 같은 학년·반·번호로는 다른 기기에서도 다시 제출할 수 없습니다. 재응시가 필요하면 교사가 결과표에서 **재응시 허용**을 누르세요.
- 점수는 항상 교사 화면에서 저장된 답안과 정답으로 다시 계산하므로 학생이 점수를 조작할 수 없습니다.
- 서버 기능(Cloud Functions) 없이 동작하도록, 제출을 마친 학생의 브라우저가 정답을 받아 채점합니다. 따라서 **제출한 학생은 기술적으로 정답을 볼 수 있습니다**(“정답 공개”를 꺼도 마찬가지). 아직 응시하지 않은 친구에게 정답이 퍼지는 것을 막으려면 모든 학생이 동시에 응시하도록 운영하는 것을 권장합니다.

## 한계

- 규칙 기반 인식이라 특이한 양식은 일부 문항을 놓칠 수 있습니다. 저장 전 확인 화면에서 꼭 점검해 주세요.
- 서술형은 핵심어·문장 유사도로만 판단하므로 뜻은 맞지만 다른 단어를 쓴 답은 “검토 요청”으로 넘어옵니다. 핵심어에 `증발|기화`처럼 같은 뜻의 말을 추가하면 자동 인정 범위가 넓어집니다.
- 문제지 한 쪽은 약 0.85MB 이하의 이미지로 저장됩니다(Firestore 문서 크기 제한).
