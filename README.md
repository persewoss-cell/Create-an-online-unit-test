# 온라인 단원평가

**사이트 주소**: https://persewoss-cell.github.io/Create-an-online-unit-test/ (GitHub Pages, 이 브랜치에 push하면 자동 배포)  
같은 사이트가 Firebase Hosting(https://create-an-online-unit-test.web.app)에도 있습니다.

교사가 **문제 PDF**를 올리고 **정답 엑셀**을 채워 올리면 온라인 평가로 바뀌고, 학생은 **학년·반·번호·이름**으로 들어와 평가를 본 뒤 **바로 자동 채점 결과**를 확인합니다. 교사는 결과를 **엑셀로 내려받고**, 자동 채점이 애매한 답안은 **검토 요청** 목록에서 직접 정답/오답을 정합니다.

## 주요 기능

## 문제지 자동 인식 (규칙 기반, AI 미사용)

과목마다 양식이 달라도 **번호가 1부터 차례로 늘어난다는 점**을 이용해 문항을 찾고, 2단 편집 시험지도 자동으로 감지합니다.

- **문항 번호**: `1.` `1)` `1번` `문제 1` `[1]` `Q1` `1 다음 중…` `4 ㉠을…` — 번호 하나를 놓쳐도 뒤 문항은 계속 찾습니다.
- **지문 묶음**: `※ 다음 글을 읽고 물음에 답하시오. (1~4)` → 1~4번은 같은 지문을 위에 고정해서 보여 줍니다.
- **문항 자르기**: 지문과 문항을 문제지에서 그대로 잘라 이미지로 보여 줍니다(그림·표 포함). 이미지는 **고화질(폭 2600px, A4 약 310dpi)**로 만들어 태블릿에서도 선명합니다. 예전에 만든 평가는 **설정 → 문제지 이미지 고화질로 바꾸기**에 같은 PDF를 올리면 이미지만 바뀝니다.
- **평가 정보 자동 채우기**: 첫 쪽 머리글(첫 문항 위)에서 `5학년 2학기`, `3-2`, 과목 이름, `2. 생물과 환경`·`5단원` 같은 단원을 찾아 채웁니다(`(1회)`, `기본 ①회` 같은 회차는 뺌). 없으면 파일 이름에서 과목을 찾습니다. 선생님이 고친 칸은 PDF를 다시 올려도 바뀌지 않습니다.
- **보기**: `①~⑤`, `㉮㉯㉰`, `㉠㉡㉢`, `(1)~(3)`(○표 문제)
- **답 쓰는 방식 자동 판단**
  - `그려 보세요`, `그어 보고`, `표시해 보세요` → 그리기 문항 (답 칸 `( )`이 있으면 그리기 + 답)
  - 그림 아래 `( ) ( )` 중 ○표 → **왼쪽/오른쪽**(세로면 위/아래) 고르기
  - 문제지 그림에서 **빈 네모 칸(□)과 `( )` 칸 수를 세어** 2개 이상이면 칸마다 입력칸 (정답은 `3, 6`처럼 순서대로)
  - `두 가지를 쓰시오`, `세 개 찾아 쓰세요` → 입력칸 2개, 3개
  - **답 칸은 문제를 읽고 고릅니다**: `다음 ( ) 안에 들어갈 말`처럼 문제 글이 가리키는 괄호와 지문·보기 속 빈칸 괄호는 답 칸으로 세지 않고, 따로 떨어진 `( )` 줄이나 `…있다. ( )`처럼 문장 끝 답 칸만 셉니다. `공통으로 들어갈 말`은 괄호가 여러 개여도 입력칸 1개
  - `풀이 과정을 쓰고` → 서술형, 선생님이 직접 채점
  - 정답 엑셀 양식의 **“답 쓰는 법”** 칸에 문항별 적는 법이 자동으로 적혀 나옵니다.

## 정답 엑셀

문제지를 인식한 뒤 **정답 엑셀 양식**(번호가 미리 채워짐)을 내려받아 `정답` 칸만 채워 올리면 됩니다. 유형·배점·핵심어는 자동으로 정해집니다.

| 문항 | 정답 칸에 적는 법 |
| --- | --- |
| 객관식 | `4` 또는 `④` (여러 개면 `2, 4`) |
| 기호로 고르기 | `㉮` |
| O/X | `O` 또는 `X` (○, × 도 됨) → O/X 문항으로 |
| ○표 하기 | `(3)` |
| 선 잇기 | `(1)-① (2)-②` |
| 단답형 | `서까래` (여러 답 인정: `로제타 선생님 / 로제타`, 모두 써야 정답: `산소, 이산화 탄소`) |
| 서술형 | 모범 답안 문장 (예시 답안: `(예) 우울한 표정 / 걱정하는 목소리 등` → 예시와 비슷하면 정답, 다르면 선생님 확인) |
| 그리기 | `그리기` (그림만) 또는 `그리기 + 3 cm` (그림 + 답 입력칸) — 항상 선생님 확인 |
| 한 문항에 여러 유형 | `;`로 나눠 적기 — 예: `왼쪽; 3 cm` → (1) 단답형 (2) 단답형. 유형은 정답 확인 화면에서 부분마다 바꿀 수 있음. **모두 맞아야 정답** |
| 선생님이 직접 채점 | `검토` — 정답 없이 저장되고 학생 답은 모두 검토 요청으로 (정답 확인 화면의 “세부 수정 → 선생님이 직접 채점” 버튼과 같음) |

### 문항·정답 수정 (등록할 때와 관리자 화면 모두)

- **객관식(선택형)**: 보기 기호 모양(①②③ / (1)(2) / ㉠㉡ / ㉮㉯ / 왼쪽·오른쪽 / O·X / 직접 입력)을 고르고, **보기 수를 −/+ 로 조절**, **＋ 보기 추가**, 보기마다 **내용을 직접 입력**(입력하면 학생 화면 버튼에 내용이 함께 보임), 삭제, 정답 표시를 할 수 있습니다. ( ) 안에 ○표 하는 문제도 여기서 보기를 늘리거나 고칠 수 있습니다.
- **단답형 칸별 정답**: 답 칸 수가 2개 이상이면 정답도 **칸마다 따로** 입력합니다(학생이 쓰는 순서대로, 한 칸에 여러 답 인정은 `/`). 기본은 **순서대로 맞아야 정답**, “순서가 달라도 정답으로 인정”을 켜면 순서 무관. 정답 엑셀에는 `3, 6, 9`처럼 쉼표로 적으면 칸마다 나뉘어 들어갑니다.
- **여러 유형**: “＋ 답 유형 추가”로 한 문항 안에 단답형·객관식·서술형·선 잇기·그리기를 섞어 (1), (2)…로 나눕니다. 학생 화면에도 부분마다 입력칸이 따로 나오고, 모두 맞아야 정답입니다.
- **답안 유형 다시 인식하기**: 세부 수정 맨 위 버튼. 그 문항만 다른 방법으로 다시 읽어(객관식 ①~⑤, 기호 고르기, ○표, O/X, 답 칸 1개/여러 개, 공통으로 들어갈 말, 서술형, 풀이 과정, 그리기, 선 잇기, (1)(2) 여러 부분…) 그럴듯한 순서대로 바꿔 줍니다. 또 틀리면 다시 누를 때마다 다음 방법으로 바뀝니다.
- **시험 중 실시간 반영**: 평가가 열려 있는 동안 문항이나 정답을 고쳐 저장하면, 시험 보는 학생 화면이 새로고침 없이 바로 바뀌고 “선생님이 ○번 문제를 고쳤어요” 알림이 뜹니다(정답만 고쳐도 알림). 실시간 연결이 끊겨도 20초마다, 화면을 다시 켜거나 인터넷이 다시 연결되면 바로 서버에서 확인합니다(형식이 바뀐 문항의 답만 지워짐). 이미 제출한 학생의 결과도 고친 정답으로 바로 다시 채점됩니다.

### 그리기 문항

학생은 문제 그림 위에 손가락·터치펜으로 바로 그립니다. 도구: 펜, 직선, 컴퍼스(중심을 누르고 끌기), 점, 지우개(획 단위), 되돌리기, 모두 지우기, **화면 속 자**(시험지 실제 크기와 같은 cm 눈금, 끌어서 옮기고 ↻로 돌리기). 그린 그림은 검토 요청과 채점된 시험지에 그대로 보입니다.

배점 칸은 비워 두면 100점을 문항 수로 나눕니다. 올린 뒤에는 문항마다 **학생이 보는 화면 그대로 정답이 초록색으로 표시**되니 확인하고 저장하세요.

> 인식 결과를 터미널에서 미리 보려면: `node scripts/inspect-pdf.mjs 문제.pdf`

## 학생 명단

선생님 화면의 **👥 학생 명단**에서 학년·반·번호·이름을 등록합니다(학교는 선생님 계정의 학교로 정해짐). 명단 엑셀 양식을 내려받아 채운 뒤 끌어다 놓으면 한꺼번에 등록되고(추가 또는 전체 바꾸기), 한 명씩 추가·수정·삭제도 됩니다. **명단에 없는 학생은 로그인할 수 없습니다**(이름까지 같아야 함 — 보안 규칙에서 서버가 확인).

## 자동 채점 기준

단답형·서술형에서 **원·네모·괄호 기호는 키보드 글자와 같게** 봅니다: `①`↔`1`, `❶`↔`1`, `⑴`↔`(1)`, `㉠`↔`ㄱ`, `㈀`↔`(ㄱ)`, `㉮`↔`가`, `ⓐ`↔`a`, `㎝`↔`cm` (태블릿 키보드로는 기호를 치기 어려우므로).

| 유형 | 정답 처리 | 교사 검토 요청 | 오답 |
| --- | --- | --- | --- |
| 객관식·선 잇기 | 번호(짝) 일치 (복수 정답은 모두 골라야 함) | – | 그 외 |
| 단답형 | (정답의 한 낱말만 쓴 경우 — 예: 정답 `점 ㅇ`, 학생 `ㅇ` — 는 선생님 검토) 띄어쓰기·문장부호·조사/어미 차이 무시 (`광합성입니다`), 활용형 차이 무시 (`많아진다`≈`많아져요`), 숫자·단위 (`24`≈`24개`, `3/4`≈`4분의 3`), 정답을 포함한 포괄적 답 | 오타로 보이는 답, 일부만 맞은 답, 단위가 다른 답 | 그 외 |
| 서술형 | 핵심어를 충분히 포함 (보통: 60% 이상) | 핵심어 일부 포함, 핵심어는 맞지만 부정 표현(`않다`)이 모범 답안과 다른 경우 | 핵심어가 거의 없음 |

검토 대기 문항은 교사가 판정할 때까지 0점으로 계산되고, 학생 결과 화면에는 `?`로 표시됩니다. 교사가 판정하거나 정답을 수정하면 **모든 학생 점수가 즉시 다시 계산**됩니다.

## Firebase 설정 (처음 한 번)

무료 요금제(Spark)로 충분합니다. Cloud Functions나 Storage는 쓰지 않습니다.

1. [Firebase 콘솔](https://console.firebase.google.com)에서 프로젝트 만들기
2. **Authentication → 로그인 방법**에서 **이메일/비밀번호**와 **익명**을 사용 설정
3. **Firestore Database → 데이터베이스 만들기** (프로덕션 모드, 위치: `asia-northeast3 (서울)`)
5. **프로젝트 설정 → 내 앱 → 웹 앱 추가** 후 표시되는 설정값을 `.env` 파일에 입력
   ```bash
   cp .env.example .env   # 값 채우기
   cp .firebaserc.example .firebaserc   # 프로젝트 ID 입력
   ```
6. 설치 및 배포
   ```bash
   npm install
   npx firebase login
   npm run deploy        # 사이트(Hosting) + 보안 규칙(firestore.rules) 배포
   ```
   배포가 끝나면 `https://<프로젝트ID>.web.app` 주소로 접속합니다.
7. 관리자 계정 만들기 (비밀번호는 6자 이상)
   ```bash
   npm run create-admin -- 원하는비밀번호
   ```
   관리자 로그인은 첫 화면 “교사 로그인” 탭 아래의 “관리자 로그인” 링크(또는 `/#/admin`)에서 비밀번호만 입력하면 됩니다. 비밀번호를 잊었을 때도 같은 명령으로 새 비밀번호를 정할 수 있습니다.

```bash
npm run test:rules     # 터미널 3: 보안 규칙 점검
```

에뮬레이터에서 관리자 로그인을 하려면 먼저 `node scripts/create-admin.mjs test1234 --emulator`로 관리자 계정을 만드세요.

`samples/` 폴더에 과목별로 양식이 다른 예시 문제·정답 PDF(과학 2단+표 정답지, 수학, 국어)가 있습니다.

## 데이터 구조와 보안

```
teachers/{uid}                        선생님 프로필(학교·학년·반) — 관리자만 만들고 고침 / 관리자 프로필은 관리 도구로만 생성
teacherLogins/{학교_학년_반}           선생님 로그인 찾기표 (로그인 전 한 건씩만 읽기 가능)
teacherSecrets/{uid}                  선생님 비밀번호 — 관리자와 본인만 (관리자가 비밀번호를 바꿔 줄 때 사용)
roster/{학교_학년-반-번호}             학생 명단 — 그 명단을 만든 선생님과 관리자만
exams/{id}                            평가 정보 + 문항(정답 없음)
exams/{id}/pages/{n}                  문제지 페이지 이미지
exams/{id}/private/key                정답 — 선생님 본인·관리자, 또는 제출을 마친 학생만 읽기 가능
exams/{id}/submissions/{학년-반-번}   학생 답안 — 한 번만 만들 수 있고 학생은 수정 불가
exams/{id}/submitters/{uid}           제출 표시
exams/{id}/drafts/{학년-반-번호}      풀던 답 임시 저장 (본인만, 제출하면 지움)
```

- 학생은 익명 로그인을 사용하며, 로그인할 때마다 새 세션이 만들어져 **공용 PC에서도 안전**합니다.
- 같은 학년·반·번호로는 다른 기기에서도 다시 제출할 수 없습니다. 재응시가 필요하면 교사가 결과표에서 **재응시 허용**을 누르세요.
- 점수는 항상 교사 화면에서 저장된 답안과 정답으로 다시 계산하므로 학생이 점수를 조작할 수 없습니다.
- 서버 기능(Cloud Functions) 없이 동작하도록, 제출을 마친 학생의 브라우저가 정답을 받아 채점합니다. 따라서 **제출한 학생은 기술적으로 정답을 볼 수 있습니다**(“정답 공개”를 꺼도 마찬가지). 아직 응시하지 않은 친구에게 정답이 퍼지는 것을 막으려면 모든 학생이 동시에 응시하도록 운영하는 것을 권장합니다.

## 한계

- 규칙 기반 인식이라 특이한 양식은 일부 문항을 놓칠 수 있습니다. 저장 전 확인 화면에서 꼭 점검해 주세요.
- 서술형은 핵심어·문장 유사도로만 판단하므로 뜻은 맞지만 다른 단어를 쓴 답은 “검토 요청”으로 넘어옵니다. 핵심어에 `증발|기화`처럼 같은 뜻의 말을 추가하면 자동 인정 범위가 넓어집니다.
- 문제지 한 쪽은 약 0.85MB 이하의 이미지로 저장됩니다(Firestore 문서 크기 제한).
